## Основное задание

### Решение

**Файл с реализацией `selectProducts`:**

src/main/kotlin/lab2/ProductSelection.kt

**Как работает функция и почему выбран такой способ обработки данных?**

Для быстрого поиска товаров по идентификаторам каталог преобразуется в Map<Long, Product>. Список исключений преобразуется в HashSet, чтобы проверять наличие идентификатора за среднее константное время. Затем функция проходит по рекомендациям и проверяет для каждого товара его наличие в каталоге, доступность и отсутствие в списке исключений. Для хранения уже добавленных идентификаторов используется отдельное множество, а подходящие товары добавляются в итоговый список

**Как сохраняются порядок рекомендаций и уникальность товаров? Как обрабатываются исключённые, недоступные и неизвестные товары?**

Результат формируется последовательным обходом recommendedIds, поэтому порядок товаров соответствует порядку рекомендаций, а не каталога. Множество addedIds предотвращает повторное добавление одного товара. Неизвестные идентификаторы пропускаются, недоступные товары и товары из списка исключений также не добавляются в результат

### Сложность

Обозначения:

- `p` — число товаров в каталоге;
- `r` — число идентификаторов в рекомендациях;
- `e` — число идентификаторов в исключениях.

**Время выполнения:**

O(p+r+e) в среднем

Преобразовать каталог в Map - O(p), а список исключений — в HashSet за O(e). Затем один проход по списку рекомендаций за O(r). Проверки наличия товара в Map и множествах в среднем выполняются за O(1)

**Дополнительная память:**

O(p+e+k)
Map с товарами O(p), множество исключённых идентификаторов O(e), множество уже добавленных идентификаторов: O(k).
Память для результата: O(k)

k - число товаров в итоговом списке (k<=r, k<=p)
